### Export Capcut Pro Video Free v1.0.1 Release

Engineered by PixelPie Media • Founded by Md. Zobaed Islam Shanto.

#### What's New in v1.0.1:
- ⌨️ **Interactive Terminal Draft Selector**:
  - Automatically scans your drives for recent CapCut projects when run from PowerShell or Command Prompt.
  - Smooth interactive keyboard navigation using `[↑]` and `[↓]` arrow keys or numbers with instant live preview.
- 💾 **Native Windows Explorer "Save As" (Ctrl+S Style)**:
  - Hit `[Enter]` on any clip in the terminal or click `Save As & Export... (Ctrl+S)` in the visual suite to open a native Windows Explorer file save dialog.
  - Pre-fills the auto-resolved project and clip name, giving you 100% control over where your clean MP4 is saved.
  - Also includes a convenient `⚡ 1-Click Desktop Export` option for zero-dialog instant recovery.
- 🧠 **Smart CapCut Project & Clip Name Resolution**:
  - Automatically inspects CapCut & JianYing internal metadata (`draft_meta_info.json`, `draft_content.json`, and CapCut AppData catalogs).
  - Resolves cryptic cache GUIDs (e.g. `48C34141-8F08-4483-A597-073963B3DB0A_video.mp4`) into clean, human-readable titles (`shining motion u - Compound clip16.mp4`).
- 🎨 **Elevated Desktop Visual Suite**:
  - Clean, agency-grade obsidian dark mode (`#0B0F14`).
  - Removed top donation banner for an uncluttered, professional interface.
  - Global keyboard shortcuts: `Ctrl+O` (Open), `Ctrl+S` (Save As & Export), `Ctrl+R` (Rescan Drafts).
  - Double-click any draft row in the Draft Library to instantly export with Save As.
- 📦 **Standalone Windows x64 Executable & ZIP Bundle**:
  - Standalone binary (`Export-CapCut-Pro-Free.exe`) with all dependencies embedded.
  - Portable ZIP bundle (`Export-CapCut-Pro-Free-Windows-x64.zip`) with desktop launchers.
