### CapCut Cache Recover v1.0.2 Release 🎬🛠️

A precision forensic stream repair and recovery engine to salvage unfinalized or corrupted CapCut & JianYing local draft video caches (BDVE Type 1) with 0% re-encoding loss.

#### What's New in v1.0.2:
- 📱 **Official Android APK (`CapCut-Cache-Recover.apk`)**: Standalone native mobile application for Android. Decrypts and recovers draft cache streams on-device via Android Storage Access Framework (SAF) and exports directly to the public device gallery (`Movies/Exported_CapCut`).
- 🐧 **Android Termux 1-Line Installer**: Run natively in Termux shell on Android with `install-termux.sh`.
- 🪟 **Windows PE Metadata Embedded**: `CapCut-Cache-Recover.exe` now carries official embedded PE version resources (`PixelPie Media`, `Md. Zobaed Islam Shanto`, Version 1.0.2.0) so Windows File Properties accurately recognizes the publisher.
- 🎯 **Interactive Terminal Selector**: Auto-indexes recent CapCut drafts with arrow-key navigation (`↑ / ↓`) and native Windows Explorer `Save As` pop-out dialog (`Ctrl+S` style).
- ⚖️ **Legal Safeguards & Forensic Safe Harbor**: Rebranded under 17 U.S.C. § 1201(f) reverse engineering for interoperability and forensic media salvage.
